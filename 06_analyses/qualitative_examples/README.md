# Qualitative Transcription Examples

Reference vs prediction examples for easy dialects (tangail, comilla) and
hard dialects (chittagong, kishoreganj), selected in the 15-90% WER range
(5-25 words) for clarity in the paper.

## Purpose

Illustrates concretely how the system performs: on easy dialects predictions
closely match references; on hard dialects (linguistically divergent) predictions
diverge, with dropped and substituted words - making the error analysis tangible.

## Files

- qualitative_examples.txt - formatted examples (ready to read)
- qualitative_examples.csv - same examples in table form (for the paper)
